# Agentes de IA na AWS — referência para squads

Apresentação didática em português no estilo YoungDevelopers / Patterns Lab, com 23 assuntos e simulações locais. Baixe o repositório e abra index.html no navegador. O material funciona offline.

O diagrama draw.io tem 16 abas. Abra o arquivo .drawio em diagrams.net. O arquivo .xml é uma alternativa sem compactação.

Ícones AWS provenientes de [AWS Icons for PlantUML](https://github.com/awslabs/aws-icons-for-plantuml).
